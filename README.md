# PS 快捷键翻牌挑战

一个纯静态网页小游戏，通过翻牌配对练习 Photoshop 常用 Windows 快捷键。

## 在线访问

https://2817014736a-dot.github.io/ps-shortcut-flip-game/

## 本地预览

直接打开 `index.html` 即可游玩。也可以在项目目录启动一个静态服务器后访问本地地址。

## GitHub Pages 部署

1. 创建公开仓库，建议名称为 `ps-shortcut-flip-game`。
2. 将本目录文件推送到仓库的 `main` 分支。
3. 在仓库设置中打开 Pages，来源选择 `Deploy from a branch`，分支选择 `main`，目录选择 `/root`。
4. 保存后等待 GitHub Pages 发布。

发布链接通常为：

```text
https://<github-user>.github.io/ps-shortcut-flip-game/
```
